# 四上自然探險島（五福國小・四年級上學期自然）

- 學校：高雄市鳳山區五福國民小學，115 學年度上學期
- 科目／版本：自然科學，**南一版 第三冊（四上）**（自然從三年級開始，四上是第三冊）
- 開啟方式：直接用瀏覽器打開 `index.html`（可離線，不需安裝、不需網路）
- 操作：滑鼠與平板觸控都可以。分類卡片可以**拖曳**，也可以**先點卡片、再點籃子**。說明與題目旁的 🔈 按鈕會朗讀（Web Speech API，需裝置有中文語音）。
- 入口：左上角「← 選年級」連到 `../index.html`（自然科年級選單）；所有檔案皆用相對路徑，只引用本資料夾內的檔案。
- 進度：星星存在瀏覽器的 localStorage（鍵名 `science-g4-progress`），首頁下方可清除。

## 檔案結構

```
index.html       入口
css/style.css    樣式（沿用三上自然風格，另加時間條、任務清單、電路控制、迷宮樣式）
js/engine.js     共用引擎：拖曳／點選、音效、朗讀、題型（quiz、sort、order、clue、combo）
js/u1.js ~ u4.js 各單元關卡資料與專屬互動（影子模擬、月相 SVG、鏡子迷宮、導電測試、串並聯模擬）
js/app.js        首頁地圖、關卡流程、星星結算
```

圖示全部使用 emoji 與程式畫的 SVG，沒有外部圖片或字型。全站共用的「回遊戲樂園」按鈕（`home-button.js`）由總管統一加入，本資料夾沒有引用。

## 核對紀錄（2026-10）

**來源（115 學年度）**

**單元目錄**：115 學年度南一四上與 114 相同——一、地球的夥伴—日月星辰（太陽、月亮與星星／多變的月亮／月相變化與生活）；二、水中世界（水中生物的生長環境／水中生物的外形與構造／愛護水域環境）；三、光和能源（光的行進方向／能量和能源轉換／節能減碳）；四、電路好好玩（讓燈泡亮的方式／電路的串聯和並聯／生活中的電）。遊戲 4 單元 12 關的名稱、順序都不用改，也沒有要增減的單元。

**修改的地方**
- 單元二「水生植物住哪裡」：分類籃與說明改用南一用語「挺水性／浮葉性／漂浮性／沉水性植物」（原為挺水／浮葉／漂浮／沉水植物）。
- 單元三「能源大挑戰」：「可再生／不可再生能源」改成南一用語「再生能源／非再生能源」；補 1 題「可以讓物體運作或改變的力量叫做能量」（課程計畫的學習目標）。
- 單元四「串並聯實驗室」：補 1 題「插座的電（電力公司送來的電）比乾電池強很多，要注意安全」（課程計畫「生活中的電」的學習目標）。
- 其餘題目逐題檢查，知識點都正確，沒有改：影子方向（面向南方、東在左）、月相 SVG 亮面方向（上弦右亮、下弦左亮）、拳頭約 10 度、鏡子迷宮 3 關都用程式確認有解且一開始不是已解狀態、串並聯亮度模擬與實際相符。

**還無法確認**
- 拿不到南一課本內文，題目用語是依課程計畫的學習目標判斷；「水中生物的生長環境」課本實際怎麼分類水域（遊戲用淡水／鹹水／河海口交界），沒有找到課本原文可以對照。
- 導電測試的「鉛筆芯」和「10 元硬幣」是依常見課本實驗列為會導電；鉛筆芯實際亮度和筆芯粗細、電池電力有關。
