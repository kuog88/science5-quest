## 對照結論
- 兩份南一 115 計畫的四個單元、順序、每單元 3 課完全一致；只有課名寫法略有差異，遊戲採西港國小的課名（較接近課本），並在 README 註記。
- 課程目標重點（兩份相同）：力的形式與受力後形狀／運動改變、可恢復與不可恢復；力的三要素（大小、方向、作用點）與箭頭表示；浮體與沉體都受浮力、浮力的應用；生物與非生物；昆蟲身體構造（頭胸腹、六腳、觸角）、校園昆蟲棲所、完全變態與不完全變態、昆蟲與生活／保育；毛細現象、連通管原理、虹吸現象；臺灣地表環境與生物、人類活動影響；礫石／砂／土壤、雨水改變地表；地震震度分級、災害與防災準備。
- 第三份明寫南一的 115 計畫在網路上沒找到（屏東、臺南、臺北查到的多為康軒），以兩份彰化計畫為準。
