# 三上自然探險島（五福國小・三年級上學期自然）

- 學校：高雄市鳳山區五福國民小學，115 學年度上學期
- 科目／版本：自然科學，**南一版 第一冊（三上）**
- 開啟方式：直接用瀏覽器打開 `index.html`（可離線，不需安裝、不需網路）
- 操作：滑鼠與平板觸控都可以。卡片可以**拖曳**，也可以**先點卡片、再點目標**。每個說明與題目旁的 🔈 按鈕會朗讀（Web Speech API，需裝置有中文語音）。
- 入口：左上角「← 選年級」連到 `../index.html`（自然科年級選單）；所有檔案皆用相對路徑。
- 進度：星星存在瀏覽器的 localStorage（鍵名 `science-g3-progress`），首頁下方可清除。

| | 流動的空氣 | 風力觀測員 | 挑戰題 | 依旗子揚起角度、樹的擺動排出風力由弱到強，再做 2 題應用題 |
| 三、認識動物 | 動物的運動 | 動物運動會 | 動手做 | 14 種動物分到「走跑／跳／飛／游／爬行蠕動」 |
| | 動物的身體、動物與生活 | 動物身體大發現 | 觀念題 | 從 11 題抽 8 題：頭軀幹四肢、昆蟲六隻腳、蹼與鰭、仿生科技（飛機、潛水艇、蛙鞋）、愛護動物 |
| | 動物的身體 | 猜猜我是誰 | 挑戰題 | 依提示猜動物（9 隻抽 6 隻），用越少提示星星越多 |
| 四、磁鐵 | 磁力的探討 | 磁鐵吸吸樂 | 動手做 | 12 樣物品分成「會／不會被磁鐵吸住」（含鋁罐、1 元硬幣等易錯題） |
| | 磁鐵的特性 | 磁極大發現 | 觀念題 | 先操作兩塊磁鐵（翻面、推過去）觀察同極相斥、異極相吸，再答 6 題 |
| | 磁鐵的特性、磁鐵與生活 | 神祕磁鐵偵探 | 挑戰題 | 5 塊隨機的未標示磁鐵，推過去看結果後判斷磁極；再加 3 題生活應用（加鐵片吸更重、指北針） |

星星計算（自然 3～6 年級上下學期一致）：答對率 = 答對次數 ÷（答對次數 + 失誤次數），失誤包含答錯、放錯、點錯、開燈沒照到、多看提示。答對率 85% 以上 3 顆星（全對或幾乎全對）、65% 以上 2 顆、40% 以上 1 顆；未滿 40% 不給星、算未過關，結果頁請孩子看重點再挑戰。純探索、沒有對錯的實驗關算全對。各關舊的 `th` 參數已不再使用。

- 其餘題目逐題檢查（植物部位分類、空氣占空間／重量／形狀、風力判斷、動物運動方式與仿生、磁鐵吸鐵／磁極／同極相斥異極相吸／加鐵片增加吸重），知識點正確，未改。

**還無法確認**：沒有拿到課本原文，題目用語是依課程計畫的學習目標比對；「昆蟲頭胸腹、六隻腳」「蜘蛛不是昆蟲」課程計畫沒有明寫，屬延伸知識，保留。

## 📘 三版本（南一・康軒・翰林）

年級頁上方有「版本／範圍」切換列（全站共用 `kg-ver.js` 的 `KGVer.bar`），單元卡片依所選版本的順序與單元名稱排列（`KGVer.units`），月考測驗卷也依版本重新組卷（`KGVer.examBank`）。對照表在 `js/book.js`，星星仍記在遊戲內部的關卡代號上，換版本不會遺失。預設版本：南一。

| 版本 | 第 1 單元 | 第 2 單元 | 第 3 單元 | 第 4 單元 |
|---|---|---|---|---|
| 南一 | 認識植物（u1） | 空氣和水（u2） | 認識動物（u3） | 磁鐵（u4） |
| 康軒 | 多采多姿的植物（u1） | 生活中的力（fo＋u4） | 奇妙的空氣（u2 第 1、2 關＋aq） | 廚房裡的科學（ds＋ab） |

- 補做與搬來的單元（每個單元 3 關：動手做／觀念題／挑戰題，都接家長報表）：
  - **生活中的力（fo）**：康軒放在三上（南一、翰林在四下）。三關從四下「生活中有趣的力」搬來（受力會怎樣？、畫出力的箭頭、浮力大考驗），改成探險島畫面，並補原子筆彈簧、水車傳送動力兩題。題庫 30 題（四下 28 題＋新 2 題）。
