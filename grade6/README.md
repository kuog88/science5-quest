# 六上自然探險島（五福國小・六年級上學期自然）

- 學校：高雄市鳳山區五福國民小學，115 學年度上學期
- 科目／版本：自然科學，**南一版 第五冊（六上）**
- 開啟方式：直接用瀏覽器打開 `index.html`（可離線，不需安裝、不需網路）
- 操作：滑鼠與平板觸控都可以。分類卡片可以**拖曳**，也可以**先點卡片、再點籃子**。說明與題目旁的 🔈 按鈕會朗讀（Web Speech API，需裝置有中文語音）。
- 入口：左上角「← 選年級」連到 `../index.html`（自然科年級選單）；所有檔案皆用相對路徑，只引用本資料夾內的檔案。
- 進度：星星存在瀏覽器的 localStorage（鍵名 `science-g6-progress`），首頁下方可清除。

星星計算（自然 3～6 年級上下學期一致）：答對率 = 答對次數 ÷（答對次數 + 失誤次數），失誤包含答錯、放錯、點錯、開燈沒照到、多看提示。答對率 85% 以上 3 顆星（全對或幾乎全對）、65% 以上 2 顆、40% 以上 1 顆；未滿 40% 不給星、算未過關，結果頁請孩子看重點再挑戰。純探索、沒有對錯的實驗關算全對。各關舊的 `th` 參數已不再使用。

## 核對紀錄（2026-10）

**來源（115 學年度、明寫南一版六上）**
- 屏東縣 115 學年度六年級自然科技領域教學計畫表（版本：南一）：https://www.cp.ptc.edu.tw/storage/134614/134614_115_B-06_6A.pdf
- 彰化縣和美國小 115 學年度第一學期六年級自然科學課程計畫（教材版本：南一）：https://curriculum.chc.edu.tw/years/115/plans/1615/views/5-6自然科學.pdf

**115 學年度南一六上目錄**：一、多樣的天氣變化（1 大氣中的水／2 天氣圖與天氣變化／3 認識颱風）；二、熱對物質的影響（1 物質受熱後的變化／2 熱的傳播方式，含熱輻射、保溫、散熱）；三、變動的大地（1 流水的作用／2 水岸地貌／3 地表組成）；四、奇妙的電磁世界（1 指北針與地磁／2 神奇的電磁鐵／3 電磁作用與生活的關係）。原本 README 依的是 114 學年度的課名。

**改了什麼**
- 單元名稱對齊 115 課名：「天氣中的水」→「大氣中的水」；單元二不再有獨立的「保溫與散熱」課，標為熱的傳播方式的一部分；單元三「岩石與礦物」「土壤與化石」→「水岸地貌」「地表組成」；單元四補「電磁作用與生活的關係」。
- 單元一：補「冰雹（雨、雪、冰雹成因）」題、補**暖鋒**符號題；**滯留鋒**符號改成正確畫法（藍紅線段交錯，三角與半圓分在線的兩側），原本三角、半圓畫在同一側。
- 單元二：補「太陽的熱以輻射傳到地球」題（課程目標「熱輻射」）。
- 單元三：**新增「流水的作用」關卡**（侵蝕、搬運、堆積，流水實驗的坡度、水量、控制變因）；河流地圖改為「水岸地貌探險」，並加海岸地形題（海蝕洞、沙灘、野柳奇岩）與中游題；「土壤與化石」關拿掉不屬於地表組成的土石流、海蝕題，改補土壤組成、岩石礦物用途（石灰岩做水泥、石墨做鉛筆芯）題；方解石提示「銅幣能刻出痕跡」改成「指甲刮不動、小刀能刻」（硬度 3 跟銅幣相近，原說法有爭議）。
- 單元四：最後一關改名「電磁生活大挑戰」，加 **電磁波** 一步（4 抽 3：哪些電器發出電磁波、睡覺手機遠離、訊號靠電磁波傳送、用電器注意事項）。
- 單元三多了一關，原本單元三第 2、3 關的星星紀錄會往後錯一格（localStorage 鍵名沒改）。

**還無法確認**
- 沒有拿到課本原文，題目用語是依兩份課程計畫的學習目標寫的；「水岸地貌」課是否也教中游、海岸地形的細節（如野柳），以課本為準。
- 屏東計畫的單元四只列兩課（電磁波放在神奇的電磁鐵最後一週），彰化列為第 3 課；遊戲照彰化分成三課。
