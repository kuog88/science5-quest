# 六上自然探險島（五福國小・六年級上學期自然）

- 學校：高雄市鳳山區五福國民小學，115 學年度上學期
- 科目／版本：自然科學，**南一版 第五冊（六上）**
- 開啟方式：直接用瀏覽器打開 `index.html`（可離線，不需安裝、不需網路）
- 操作：滑鼠與平板觸控都可以。分類卡片可以**拖曳**，也可以**先點卡片、再點籃子**。說明與題目旁的 🔈 按鈕會朗讀（Web Speech API，需裝置有中文語音）。
- 入口：左上角「← 選年級」連到 `../index.html`（自然科年級選單）；所有檔案皆用相對路徑，只引用本資料夾內的檔案。
- 進度：星星存在瀏覽器的 localStorage（鍵名 `science-g6-progress`），首頁下方可清除。

星星計算：依失誤次數（答錯、放錯、點錯位置、多看提示）給 1～3 顆星，門檻寫在各關的 `th` 參數。

## 檔案結構

```
index.html       入口
css/style.css    樣式（沿用四上自然風格，另加熱點與實驗數值樣式）
js/engine.js     共用引擎：拖曳／點選、音效、朗讀、題型（quiz、sort、order、clue、combo），以及實驗任務清單 labTasks
js/u1.js ~ u4.js 各單元關卡資料與專屬互動（露霜實驗、天氣圖符號、熱脹冷縮、河流地圖、電磁鐵模擬）
js/app.js        首頁地圖、關卡流程、星星結算
```

圖示全部使用 emoji 與程式畫的 SVG，沒有外部圖片或字型。全站共用的「回遊戲樂園」按鈕（`home-button.js`）由總管統一加入，本資料夾沒有引用。
