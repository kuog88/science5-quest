# 五上自然闖關探索館

國小五年級上學期自然科（南一版）的互動學習與闖關網站，四個單元、十課：

| 單元 | 課次 |
|---|---|
| 一、太陽與光 | 太陽在天空中的位置變化、認識光的現象與特性 |
| 二、植物世界 | 植物根莖葉的功能、植物的繁殖與人類生活 |
| 三、水溶液 | 溶解現象、水溶液的酸鹼性、水溶液的導電性 |
| 四、力與運動 | 力的測量、摩擦力、運動狀態的快慢 |

## 玩法

1. **學習**：點圖上的圓點或按鈕，會跳出大卡片，附寫實照片並唸出講解；每課還有互動小實驗（拉時間軸看太陽、加糖溶解、換水溶液測導電、掛砝碼拉彈簧……）。
2. **闖關**：學完按「開始闖關」，換到闖關頁。題庫共 235 題，每次隨機抽 8 題，上一回出過的題目會排到最後，包含直接點圖作答的題目；答對 6 題過關，依錯誤次數拿 1～3 顆星，過關播放動畫。
3. **魔王關**：同一單元每課都過關後開放，10 題、3 顆愛心。

闖關進度存在瀏覽器裡（localStorage），換裝置不會帶過去。建議用 Chrome 或 Edge，中文語音最完整。

## 檔案

```
index.html        主頁面
css/style.css     樣式
js/units.js       單元設定與畫圖小工具
js/u1.js ~ u4.js  各單元的圖解、講解、題庫
js/app.js         首頁、學習頁、闖關頁
assets/           過關動畫與吉祥物圖片
media/            寫實照片（可靈 AI 生成），檔名為「課號-部位.jpg」
```

## 換照片、加影片或配音

把檔案放進 `media/`，檔名用「課號-部位」：

- `u2a-root.jpg`：照片，取代卡片上的手繪圖
- `u2a-root.mp4`：影片，有的話會優先播放
- `u2a-root.mp3`：自己錄的配音，取代電腦語音

課程進度依高雄市鳳山區五福國小 115 學年度五年級上學期自然科課程計畫整理。
