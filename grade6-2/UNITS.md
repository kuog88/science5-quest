# 六下自然 單元目錄（115 學年度，三版本）

資料來源：`curriculum/science.json`（彰化縣 115 學年度學校課程計畫逐份核對表頭版本）。

## 南一
- 第 1 單元 巧妙的施力工具：認識槓桿、滑輪與輪軸、傳送動力
- 第 2 單元 地球的環境與生態：族群與群集、生物間的交互作用、地球的生態系
- 第 3 單元 我們只有一個地球：臺灣的生態、人類活動對環境的影響、打造永續家園

## 康軒
- 第 1 單元 簡單機械：如何運用槓桿、輪軸與滑輪如何便利生活、還有哪些傳送動力的機械
- 第 2 單元 能量與生活：能量如何互相轉換、生活中如何利用能源
- 第 3 單元 地球的生態：生物彼此間有什麼關係、不同生態系中的生物有什麼不同、如何維護生物多樣性

## 翰林
- 第 1 單元 簡單機械：槓桿、輪軸、滑輪、齒輪與鏈條
- 第 2 單元 生活中的聲音：有聲的世界、聲音的性質、自製簡易樂器
- 第 3 單元 寰宇永續護地球：生物與環境、人類活動對生態的影響、資源開發與永續經營
