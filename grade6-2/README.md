# 六年級下學期・蒸氣齒輪工坊（自然，南一・康軒・翰林三版本）

六下自然互動闖關（整冊新做，一開始就做三版本）。入口：`index.html`，可離線遊玩，滑鼠、觸控都能操作。

## 主題說明
- 主題：**蒸氣齒輪工坊**——戴上護目鏡當小工程師，轉動槓桿與齒輪、守護地球的生態。
- 配色：深咖啡頂欄＋黃銅（#b5862a）＋鐵灰＋羊皮紙底，和六上「自然探險島」（天空藍＋草綠）明顯不同。
- 頁首有橘色「下學期」標籤；`<title>`、首頁標題都寫「六年級下學期」；關卡標題 `h2#level-title.level-title`。
- 進度存在 localStorage `science-g6-2-progress`（和上學期分開）；左上角「← 選年級」連到 `../index.html`。
- 首頁上方 `KGVer.bar` 切換版本與月考範圍，單元卡片依版本順序與名稱排列；星星記在遊戲內部代號（`mc-1`…）。

## 核對紀錄
- 單元目錄見 `UNITS.md`（來源為彰化縣 115 學年度各校課程計畫，三版各 2～4 份）。
- 學習內容依 108 課綱 INe-Ⅲ（槓桿、輪軸、滑輪、齒輪傳動）、INb-Ⅲ／INg-Ⅲ（族群、群集、交互作用、生態系、生物多樣性、人類活動與永續）、INa-Ⅲ（能量轉換、聲音）。題目自行編寫，沒有複製課本或習作。
- 槓桿與齒輪的計算題都以「砝碼數×格數」「齒數×圈數」驗算過。
- 仍不確定：各版本活動內是否教「三種槓桿（第一、二、三類）」的名稱，本冊只用「省力／費力／不省力也不費力」說法；康軒「能量與生活」中能量形式的用詞（化學能、動能等）以常見說法為準。
- 測試：node 檢查全過；瀏覽器 18 關全部玩完 30/30（南一）、康軒、翰林切換後單元與名稱正確；三版期中試卷、南一期末試卷都能作答交卷；375 寬無橫向捲動；console 無錯誤。
