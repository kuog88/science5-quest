# 三年級下學期・星光科學觀測站（五福國小・三年級下學期自然）

- 學校：高雄市鳳山區五福國民小學，115 學年度**下學期**
- 科目／版本：自然科學，**南一版 第二冊（三下）**
- 開啟方式：直接用瀏覽器打開 `index.html`（可離線，不需安裝、不需網路）
- 操作：滑鼠與平板觸控都可以。卡片可以**拖曳**，也可以**先點卡片、再點目標**。說明與題目旁的 🔈 按鈕會朗讀（Web Speech API）。
- 入口：左上角「← 選年級」連到 `../index.html`；所有檔案皆用相對路徑。
- 進度：星星存在 localStorage，鍵名 `science-g3-2-progress`（和上學期的 `science-g3-progress` 分開），首頁下方可清除。

## 檔案結構
```
index.html       入口
css/style.css    夜空主題樣式
js/engine.js     共用引擎（拖曳／點選、音效、朗讀、題型 quiz／sort／order／combo），沿用上學期並改用下學期的 localStorage 鍵
js/u1.js ~ u4.js 各單元關卡資料與專屬互動（燒杯與溫度計、風向風力計、氣溫折線圖、砂糖溶解杯、高麗菜汁試管）
js/app.js        首頁觀測站、關卡流程、星星結算
UNITS.md         核對後的單元目錄與來源
```
圖示全部使用 emoji 與程式畫的 SVG，沒有外部圖片或字型。
